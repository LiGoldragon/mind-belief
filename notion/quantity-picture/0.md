# The picture of a quantity

```ethos sketch
Types
[ Measure.{ Name.String
            Used.Integer
            Expected.Integer
            Limit.Integer }
  Standing.[ Ahead Even Behind ]
  QuantityPicture.{ Question.String
                    Vector<Measure> } ]
```

```datom
{ «Are we spending each week before it resets?»
  [ { «Claude, all models» 35 46 100 }
    { «Codex» 20 60 100 } ] }
```

```datom
[ { Question «the one headline, the largest words: what the picture answers» }
  { Measure «one horizontal bar; its Name at its left» }
  { Limit «the full length of the bar's track; every bar on the same scale, left edges aligned» }
  { Used «the filled part of the bar, with its number at the end of the fill, large» }
  { Expected «a bold vertical tick across the bar, where Used would stand by now» }
  { Standing «the gap between fill and tick, in one colour for Ahead, another for Behind» }
  { Time «left to right; the reset is the right edge, with the days left written there» }
  { Words «names and numbers only; no sentence anywhere but the Question» }
  { Order «the bar furthest from its tick first» } ]
```
