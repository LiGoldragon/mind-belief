When a source needs a sentence beside it, the language lacks a word: the Designer adds the word here, the visualizer reads the lines added, and the proposal that needed it shows the addition among its own units. The picture the living approves for a word is part of this module: it is kept beside it, named for its word, and the drawer opens it before drawing that word. A word of the language says whole what the thing does, in as many words as that takes. A chart holds types and values of types, in place, and nothing named beside them: a further level of abstraction is a further type.

```ethos sketch
Types
[ Verb.String
  Quality.[ Solar Lunar Martial Mercurial Jovian Venusian Saturnian Ascending Descending ]
  Happening.[ Does.Verb
              May.Verb
              BothWays.Verb
              Stopped ]
  Link.{ From.Datom
         To.Datom
         Happening }
  Then.[ Ends Again ]
  Case.{ Name.String
         Option<Quality>
         ⟦ Link ⟧
         Then }
  Form.[ Down Across ]
  Chart.{ Form
          Types.⟦ Ethos ⟧
          ⟦ Link ⟧
          ⟦ Case ⟧ } ]
```

## The bootstrap

These sentences are for the drawer alone and are shown to no one.

```datom
[ { Chart «its Types are the Ethos of every type its datoms use, given once; they are read, and drawn only where a datom is drawn» }
  { Datom «each end of a link is a datom headed by its type, Role.Designer, Page.{ Title 7 }; it is drawn as that datom, by its type's Ethos, the head left unwritten where the datom shows what it is» }
  { Once «equal datoms are one object, drawn once; every link that names it meets that one drawing» }
  { AnyValue «a type's name alone stands for any value of it: the name in that type's delimiters, empty» }
  { Struct «two blue braces, large, around a pale field, one chip for each field, in order» }
  { Enum «a value of an enum is its variant's name in the enum's two green square brackets, on a pale field» }
  { Vector «two white square brackets, green, a double stroke, around its items in a row» }
  { Text «grey guillemets around the words, in the reading face» }
  { Nested «a datom inside a datom is drawn whole on the outer field, its own delimiters and its own pale field» }
  { Sign «a value of Sign is its sign of notion:symbols:0, drawn alone» }
  { Link «one curved arrow from its first datom to its second» }
  { Does «the verb stands on the arrow» }
  { May «a dashed arrow with its verb» }
  { BothWays «one arrow with a head at each end, its verb on it» }
  { Stopped «the arrow ends at a bar before the datom» }
  { Case «its links in order, drawn on the one drawing of the objects, its arrows in its quality's strong colour: Solar gold, Lunar blue, Martial red, Mercurial green, Jovian yellow, Venusian pink, Saturnian grey, Ascending slate blue, Descending smoke» }
  { Again «after the case's last link the chart's own links happen again: its last arrow runs on into the first of them, closing a loop» }
  { Ends «the case stops at its last link» }
  { Down «the objects one under another, first at the top» }
  { Across «the objects side by side, first at the left» } ]
```
