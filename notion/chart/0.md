When a source needs a sentence beside it, the language lacks a word: the Designer adds the word here, the visualizer reads the lines added, and the proposal that needed it shows the addition among its own units. The picture the living approves for a word is part of this module: it is kept beside it, named for its word, and the drawer opens it before drawing that word. A word of the language says whole what the thing does, in as many words as that takes.


## The bootstrap

These sentences are for the drawer alone and are shown to no one.

```datom
[ { Chart «its Types are the Ethos of every type its values use, given once; they are read, and drawn only where a value is drawn» }
  { Value «every object of the system is a value: its type named, its datom drawn by that type's Ethos» }
  { Struct «two blue braces, large, around a pale field, one chip for each field, in order» }
  { Vector «two white square brackets, green, a double stroke, around its items in a row, first to last, alike in size» }
  { Variant «a chip with the variant's name, bold; what it carries follows it, joined» }
  { Text «grey guillemets around the words, in the reading face» }
  { Nested «a value inside a value is drawn whole on the outer field, its own delimiters and its own pale field» }
  { Abbreviated «the fields it names alone, in delimiters that keep their true shape and are cut by about four clear gaps each» }
  { Glyph «a sign of notion:symbols:0, drawn alone» }
  { Quality «the colour of the object's field and of the arrows that leave it: Solar gold, Lunar pale blue, Martial red, Mercurial green, Jovian yellow, Venusian pink, Saturnian grey, Ascending slate blue, Descending smoke; an object with none is ink on the ground» }
  { Name «an object's name is for the links and is not written» }
  { Path «the object's name, then the names of fields, types or variants inside it, down to the part meant» }
  { Link «one curved arrow from its object to the part its path names, landing on it» }
  { Does «the verb stands on the arrow» }
  { May «a dashed arrow with its verb» }
  { BothWays «one arrow with a head at each end, its verb on it» }
  { Stopped «the arrow ends at a bar before the part» }
  { Case «its links in order; every case is drawn on the one drawing of the objects; a case with a quality has its arrows in that quality's strong colour» }
  { Down «the objects one under another, first at the top» }
  { Across «the objects side by side, first at the left» } ]
```
