When a source needs a sentence beside it, the language lacks a word: the Designer adds the word here, the visualizer reads the lines added, and the proposal that needed it shows the addition among its own units. The picture the living approves for a word is part of this module: it is kept beside it, named for its word, and the drawer opens it before drawing that word. A word of the language says whole what the thing does, in as many words as that takes.

```datom
[ { Value «a value of the system, given with the Ethos of its type and drawn as its datom by that type: a struct in braces with one chip for each field, a variant as its name joined to what it carries; a value that names a thing one can see is drawn as that thing» }
  { Type «a type of the system, drawn as its Ethos, the same way» }
  { Abbreviated «the fields it names alone, in delimiters that keep their shape and are cut by gaps» }
  { Glyph «the Sun is the living, the Moon the written psyche» }
  { Thing «a round-cornered frame with its name» }
  { Holding «a frame with its objects inside it» }
  { Sequence «its objects in a row, first to last, alike in size» }
  { Measure «a length filled as far as its amount, on the scale of its whole» }
  { Name «written on a Thing; every other body says what it is» }
  { Quality «the colour of the object's field, pale; an object with none is ink on the ground» } ]
```

```datom
[ { Link «one curved arrow from its object to its place, in the strong colour of the object it leaves» }
  { At «the arrow lands on the object» }
  { Before «the arrow lands in the gap before the object» }
  { After «the arrow lands in the gap after the object» }
  { Does «the verb stands on the arrow» }
  { Silent «no word: the landing says it» }
  { May «a dashed arrow with its verb» }
  { BothWays «one arrow with a head at each end» }
  { Cuts «the arrow lands and the object is cut in two» }
  { Stopped «the arrow ends at a bar before the object» }
  { Carries «the arrow is as wide as its amount» }
  { Becomes «the object is drawn in that state» }
  { Case «its steps in order; every case is drawn on the one drawing of the objects» } ]
```
