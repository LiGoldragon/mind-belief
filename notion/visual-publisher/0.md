# The visual publisher

The visual publisher is given a page, as datom, and publishes it as made, publicly.

```ethos
Types
[ PicturePath.String
  ModulePath.String
  Words.Integer
  Code.{ Language.String
         Text.String }
  Change.[ Added.PicturePath
           Removed.PicturePath
           Replaced.{ PicturePath PicturePath }
           Standing.PicturePath ]
  Unit.{ Change Words Option<Code> }
  Section.{ ModulePath
            Reviewing.String
            Vector<Unit> }
  VisualPage.{ Title.String
               Signature.String
               Vector<Section> } ]
```

The datom, a page of one section and two units; its names are examples:

```datom
{ «A proposal, shown»
  «Created by Fable. Drawn by the visualizer.»
  [ { «psyche-belief › vision/example/0.md»
      «A new module.»
      [ { Added.«pictures/1.svg» 19 None }
        { Replaced.{ «pictures/2-out.svg» «pictures/2.svg» } 24 Some.{ ethos «Example.String» } } ] } ] }
```

The page opens with its title and its signature. Each section is headed by its module's path, then its one line saying what is reviewed. Under it stand its units in order, each one picture, large, with its number of words.

An added picture shows under the green margin, a removed one under the red; a replaced unit shows the outgoing picture under the red beside the incoming under the green; a standing picture shows under no margin. A unit's code shows as code, highlighted in its language, beside its picture.

The page holds no other words.

A page given again replaces the one published under the same title.

It answers the sender of the page when the page is published, with the page's public address, or with what stopped it.
