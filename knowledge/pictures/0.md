A picture reaches a model as a picture through the typed prompt, in Claude Code and in Codex, and through a tool result or a file the flow opens itself.

Entry files, hooks, skills, briefs and subflow reports carry text only; a picture there is a path the model opens.

At the top stratum, the Anthropic Messages API takes text alone in system. The OpenAI Responses API takes an input_image in a system or developer message; Codex injects one as a developer-role item, while its base and developer instructions are strings.

Text outranks a picture: an instruction in a picture is followed when it stands alone, and loses to contrary text at any stratum.

A picture binds through the text that names it. A line at the middle stratum or above that names a picture as the rule makes the model follow the picture when it opens it; a Claude hook lends no such authority, and a line at the bottom lends none.

A module that rests on a picture names the picture in its text and says what it governs.

Claude reads a picture at about (width ÷ 28) × (height ÷ 28) tokens, capped near 1,600; Codex takes about 520 for 1200×300. The picture is paid on every turn until compaction.

Mermaid or code carries structure and labels in 165 to 250 tokens, where a picture 1000 pixels wide costs 1,100 to 2,100. Colour is written into the Mermaid with classDef and linkStyle, for about 100 tokens more.

A picture beats text per token only at 180 to 250 pixels wide, where Sonnet still reads it and Haiku begins to fail. A legend that gives a colour an arbitrary meaning is obeyed.

Claude drops a picture at compaction and keeps it across a resume before one. Codex keeps a typed picture through both and drops a developer-role picture at compaction.

Tried on 21 November 2026 with Haiku, Sonnet and a cheap Codex model, a few runs each, and read from the vendors' documentation and published studies.
