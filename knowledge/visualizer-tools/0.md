## Fonts and icons

Use `DejaVu Sans` for SVG text; set `font-family="DejaVu Sans, sans-serif"`. Fontconfig resolves the regular and bold files:

```sh
fc-match -f '%{file}\n' 'DejaVu Sans'
fc-match -f '%{file}\n' 'DejaVu Sans:weight=bold'
```

Tabler icons: `/home/li/primary/flows/1b5896/marks/icons/tabler/`.

## SVG and preview

Write the SVG in the harness scratchpad. Run an SVG-generating script with `/home/li/.nix-profile/bin/python3 drawing.py`. Render a local preview and open the PNG to inspect the picture:

```sh
/home/li/.nix-profile/bin/magick -density 80 1.svg 1.png
```

## Page and pictures

Put each picture where its order names. When the order names no place, keep `page.datom` in a page directory under the drawing flow's directory. Put the final SVGs in its sibling `pictures/` directory, and reference them in the datom as `pictures/1.svg`, `pictures/2.svg`, and so on. Keep a PNG preview beside its SVG if needed for inspection. Pass the absolute `page.datom` path to the visual publisher.

```text
/home/li/primary/flows/0738d8/visualcheck/
  page.datom
  pictures/
    1.svg
    2.svg
```
