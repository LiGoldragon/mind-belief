A Mind flow's handover lets a fresh flow find its way through the code its predecessor came to know. It names the repositories, branches and files the work lives in; where each part of the work sits in them; the types, traits and functions that carry it and how they connect; how the code is built and tested; and where the work stands in that code, with the next change to make.
