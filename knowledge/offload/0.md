Heavy work runs on the builder, the host the laptop's Nix already builds on: the host of the `ssh-ng://` line in `/etc/nix/machines`. The laptop keeps editing, git, the flows' clients and reading results.

A Nix build is run where the flow is, with `nix build`; Nix sends the building to the builder itself.

```sh
nix build --no-link 'github:<owner>/<repo>?rev=<full-rev>#checks.x86_64-linux.default'
```

A Nix evaluation is pure for a pushed revision: the same revision gives the same derivation on any host, so a heavy evaluation runs on the builder by its revision.

```sh
ssh <builder> "nix eval --raw 'github:<owner>/<repo>?rev=<full-rev>#<attribute>'"
```

Work in progress is compiled and tested on the builder through the synchronized tree, as knowledge:development:0 says.

Output returns on standard output; a file is copied back only when it is wanted. A host's whole system is evaluated by Lojix, not by hand.
