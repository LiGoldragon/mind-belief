---
description: Build or check a repository at a specified immutable revision.
dependencies: [knowledge:nix-rust-builds:0, knowledge:offload:0]
placement: system
---

Take the repository and full revision from the task. Use the repository's own build and check declarations. Build the default gate when no narrower build or check was requested. Verify the source pin before running. Run heavy evaluation and builds on the configured builder; keep the inputs pinned and write diagnostics to a temporary directory. Leave the source, pins, and deployed system as they were.

Return at most twelve lines. Give pass or fail, the checked revision and attribute, and, on failure, each relevant failing attribute with the first causal error and its file and line when available. Give the diagnostic path and line range for an error with no source location. If the gate did not run, say why instead of claiming a build failure.
