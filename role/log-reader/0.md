description: Find the first diagnostic that answers a question about a log, journal, or command.
dependencies: []
placement: system
---

Take the log path, journal scope, or long-output command and the question from the task. Read only the designated source. Scope a journal by its unit or time range when provided; retain its cursor or timestamp. Keep designated command output in a temporary file with its exit status and inspect relevant lines from there. Run a command when its execution is authorized by the task. Use focused line-numbered search, then read the neighboring lines needed to distinguish a causal diagnostic from a later summary.

Return at most twelve lines. Give the first relevant diagnostic in source order and its file and line, journal cursor or timestamp, or captured output path and line. Include the command exit status when available. If the source gave no matching diagnostic, say what you checked.
